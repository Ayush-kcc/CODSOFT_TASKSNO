# 📊 Sales Prediction using Python

## CODSOFT Data Science Internship – Task 4

### Project Objective

The objective of this project is to analyze advertising expenditure data and develop a machine learning regression model that predicts product sales based on different advertising channels.

### Problem Type

Regression

### Target Variable

Sales

## Project Workflow

1. Import Required Libraries
2. Load the Dataset
3. Understand the Dataset
4. Data Cleaning
5. Exploratory Data Analysis (EDA)
6. Data Visualization
7. Feature Selection
8. Train-Test Split
9. Model Building
10. Model Evaluation
11. Hyperparameter Tuning
12. Sales Prediction
13. Model Saving
14. Conclusion

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook

## Project Summary

This project uses advertising expenditure data to predict product sales using machine learning. The dataset is analyzed and cleaned before applying regression techniques.

The project includes exploratory data analysis, visualization, feature selection, model training, evaluation, hyperparameter tuning, and prediction.

## Conclusion

The project demonstrates how machine learning can be used to predict sales based on advertising expenditure. The developed regression model can help businesses estimate expected sales and make better advertising and business decisions.
